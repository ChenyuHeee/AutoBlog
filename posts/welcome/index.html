Welcome to AutoBlog

January 01, 2025

AutoBlog turns Markdown files into a static site that works nicely with GitHub Pages.

  • Write posts in the source/posts/ directory.
  • Run python build.py to regenerate the site.
  • Push the repository and let GitHub Pages serve the public/ folder.
